# 1.Gemini Function Declarations (Updated)

Convert existing text-prompt tool registry definitions into formal Gemini `FunctionDeclaration` objects with JSON Schema / OpenAPI 3.0 parameter definitions (`type: 'object'`). Provide these declarations to the Gemini 2.5 Flash model via `@google/genai` SDK configuration (`config.tools[0].functionDeclarations`) without executing any tool backend calls.

## Proposed Changes

---

### Backend AI Module

#### [MODIFY] [toolRegistry.js]

- Retain `getAvailableTools()` for backwards compatibility (returns `{ name, description }` objects).
- Export `getGeminiFunctionDeclarations()` returning an array of valid Gemini `FunctionDeclaration` objects.
- Preserve exact existing tool names and descriptions.
- Use standard lowercase schema types (`type: 'object'`, `type: 'string'`, `type: 'boolean'`) consistent with `@google/genai` JavaScript schema representations.
- Map all 6 registered tools with exact backend-aligned input parameter schemas:
  1. **`searchAnnouncements`**:
     - `description`: `'Search faculty announcements'`
     - `parameters`: `type: 'object'`, properties: `query` (string), `category` (string).
  2. **`checkVotingEligibility`**:
     - `description`: `'Check whether the current student is eligible to vote'`
     - `parameters`: `type: 'object'`, properties: `electionId` (string, optional).
  3. **`searchLostItems`**:
     - `description`: `'Search reported lost and found items'`
     - `parameters`: `type: 'object'`, properties: `query` (string), `type` (string: `lost` | `found`), `category` (string).
  4. **`submitComplaint`**:
     - `description`: `'Submit a student complaint'`
     - `parameters`: `type: 'object'`, properties: `title` (string), `description` (string), `category` (string), `targetAdminType` (string), `isAnonymous` (boolean). Required: `['title', 'description']`.
  5. **`getComplaintStatus`**:
     - `description`: `'Get the status of a submitted complaint'`
     - `parameters`: `type: 'object'`, properties: `complaintId` (string, optional).
  6. **`getNotifications`**:
     - `description`: `'Retrieve notifications for the current user'`
     - `parameters`: `type: 'object'`, properties: `unreadOnly` (boolean, optional).

### Backend Controller

#### [MODIFY] [aiChatController.js]

- Import `getGeminiFunctionDeclarations` from `../ai/tools/toolRegistry`.
- Retrieve Gemini function declarations and pass them in `config.tools` to `client.models.generateContent`:
  ```javascript
  const functionDeclarations = getGeminiFunctionDeclarations();
  const response = await client.models.generateContent({
    model: GEMINI_MODEL,
    contents: prompt,
    config: {
      tools: [{ functionDeclarations }],
    },
  });
  ```
- Strictly do NOT execute any requested tools in Topic 1.
